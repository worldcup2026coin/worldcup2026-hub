# WC26 AI Workflow Pack

This folder contains project-specific AI workflows for the WorldCup2026Coin / worldcup2026-hub project.

Use these workflows as review prompts before launch, during launch, and after major changes.

## Files

### launch-audit.md
Full launch readiness review covering routes, build, QA, content, safety, and release blockers.

### crypto-copy-audit.md
Checks all $WC26 and crypto-related wording for unsafe claims, official-sounding language, presale language, investment promises, and missing disclaimers.

### mobile-ui-audit.md
Checks mobile layout, sticky CTA behavior, overflow, spacing, readability, and route-by-route mobile credibility.

### social-launch-content.md
Generates safe X/Twitter and Telegram launch content without profit claims, official claims, or fake urgency.

### supabase-security-review.md
Reviews Supabase, auth, admin, account, community, prediction, cron, and API security.
